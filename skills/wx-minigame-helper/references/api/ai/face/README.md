# AI 能力 / 人脸核验

## 文档列表

| 文档 | 说明 |
|---|---|
| [wx.faceDetect(Object object)](wx.faceDetect.md) | 人脸检测，使用前需要通过 wx.initFaceDetect 进行一次初始化，推荐使用相机接口返回的帧数据。本接口不再维护，请使用 wx.createVKSession 接口代替。详情参考人脸检测指南 |
| [wx.initFaceDetect(Object object)](wx.initFaceDetect.md) | 初始化人脸检测。本接口不再维护，请使用 wx.createVKSession 接口代替。详情参考人脸检测指南文档 |
| [wx.stopFaceDetect(Object object)](wx.stopFaceDetect.md) | 停止人脸检测。本接口不再维护，请使用 wx.createVKSession 接口代替。详情参考人脸检测指南文档 |
