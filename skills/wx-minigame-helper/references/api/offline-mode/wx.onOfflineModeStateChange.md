# wx.onOfflineModeStateChange(function callback)

> 基础库 3.16.0 开始支持，低版本需做[兼容处理](<../../guide/runtime/client-lib/compatibility.md>)。

## 功能描述

监听离线模式状态变化事件。当离线模式的启用状态发生改变时触发回调。

## 参数

### function callback

离线模式状态变化事件的回调函数
