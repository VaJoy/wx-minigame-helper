# 离线模式

> 路径：`api/offline-mode/`　|　本目录 3 篇

## 文档列表

| 文档 | 说明 |
|---|---|
| [wx.enableOfflineModeDebug(Object object)](wx.enableOfflineModeDebug.md) | 开启或关闭离线模式调试。仅在开发版和体验版中可用，正式版中调用会失败。若服务端已配置离线模式，则无法通过此接口修改。 |
| [wx.offOfflineModeStateChange(function callback)](wx.offOfflineModeStateChange.md) | 取消监听离线模式状态变化事件。 |
| [wx.onOfflineModeStateChange(function callback)](wx.onOfflineModeStateChange.md) | 监听离线模式状态变化事件。当离线模式的启用状态发生改变时触发回调。 |
