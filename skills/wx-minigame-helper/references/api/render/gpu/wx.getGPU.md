# GPU|undefined wx.getGPU()

> **微信 Android 版** ：支持

## 功能描述

获取 WebGPU 的 GPU 对象，等价于 Web 端的 navigator.gpu。仅 Android 平台支持。

## 返回值

### GPU|undefined

GPU 对象，等价于 Web 的 navigator.gpu；非 Android 平台返回 undefined
