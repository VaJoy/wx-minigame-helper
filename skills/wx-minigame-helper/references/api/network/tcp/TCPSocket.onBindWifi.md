# TCPSocket.onBindWifi(function listener)

> 基础库 3.1.1 开始支持，低版本需做[兼容处理](<../../../guide/runtime/client-lib/compatibility.md>)。

> **微信 Windows 版** ：支持
> 
> **微信 Mac 版** ：支持
> 
> **微信 鸿蒙 OS 版** ：支持

## 功能描述

监听当一个 socket 绑定当前 wifi 网络成功时触发该事件

## 参数

### function listener

当一个 socket 绑定当前 wifi 网络成功时触发该事件的监听函数
