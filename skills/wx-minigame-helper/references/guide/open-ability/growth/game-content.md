# 微信游戏圈认证账号内容规范及处理规则

## 1、认证账号范围

包含蓝v账号和黄v两类，蓝v是各个游戏或平台的官方认证账号；黄v是经游戏官方或平台认证的创作者、媒体账号、大神团、圈主等账号。

**认证账号示意：**

认证账号在圈子、内容流及个人主页均享有专属标识与显著展示，在社区有着更高的影响力，因此平台对此类账号在游戏圈内的言行将严加规范。请认证用户在主页资料、内容发布（含发帖、评论）及私信交互中，自觉遵守平台规则，共同维护良好的社区生态。

![](https://mmgame.qpic.cn/image/bdce3492b30c771c7355625a35e9e9110017f81087e605b09e16d714804b0611/0)

## 2、平台鼓励的内容范式

2.1 平台鼓励发表格式清晰、行文简练、信息完整的内容，例如在pc端发表图文贴，尽可能图文并茂、有排版有封面，避免过长且不分段的文本。

2.2 平台鼓励各类认证账号发布真实、原创、对玩家有价值的内容，认证账号发表他人原创或投稿内容需取得授权并标明。

2.3 平台鼓励各类认证账号多发表游戏热点相关、专业性和互动性强的内容，如活动爆料、版本更新盘点等，引领玩家参与讨论。

## 3、认证账号需避免的内容及处理规则

3.1 禁止发布违反法律规定的内容

​​ 3.1.1 在发帖和评论中表达不当政治立场、出现歪曲历史等涉政敏感内容；

​​ 3.1.2 含有或暗示违法、犯罪、暴力以及违背社会道德准则的内容；

​​ 3.1.3 提及赌博相关玩法或宣扬游戏中具备赌博性质的功能，包括但不限于不得出现老虎机、炸金花、梭哈、百家乐、21点、赌马等涉赌玩法或素材。

  

**处理规则：**

如认证账号发布违反以上社区规则的内容，平台将对账号进行全场景永久禁言、禁发内容的处置，并永久封禁账号的使用权限。

3.2 禁止发布虚假宣传、不正当引流的内容

​​ 3.2.1 使用猎奇素材、色情暗示、低俗擦边内容作为文章配图或视频，吸引点击；

​​ 3.2.2 在无官方合作的情况下，不得冒用其他IP或以其他游戏名义宣传自己的游戏，如使用认证账号发布A游戏攻略内容，实际引导跳转B游戏；

​​ 3.2.3 宣传内容与实际情况不符，如免费兑换码、超低折扣、大额返现等吸引点击，实际游戏内活动不一致的宣传词不能发；

​​ 3.2.4 禁止借国家热点内容进行营销，如“庆祝神舟发射，加圈送火箭模型”；

​​ 3.2.5 禁止引导用户至外部平台下载、使用小游戏，或将用户引流至外部平台等可能给用户带来风险的行为；

​​ 3.2.6 禁止发布、传播其他平台的营销广告内容，如原创内容中涉及营销部分，需剪辑处理后再发布。

  

**处理规则：**

针对上述违规行为，平台将执行以下阶梯式处罚机制：

首次违规： 予以警告，并对该游戏圈账号实施全场景禁言及禁止发布内容7天的处理；

多次违规： 视情节严重程度，将升级处罚力度，对账号实施30天至永久的全场景禁言及禁止发布内容处理；情节极端恶劣者，将永久收回账号使用权限（封号）。

3.3 禁止发布不友善言论

​​ 3.3.1 禁止发布辱骂、飙脏话、不尊重他人、人身/地域/族群攻击等内容；

​​ 3.3.2 认证账号需避免针对社区其他玩家制造或参与冲突，不得挑动对立情绪、挑起网络暴力戾气、宣扬恐慌焦虑情绪等；

​​ 3.3.3 官方玩梗整活应注意尺度，不得在同类游戏厂商之间拉踩引战，如嘲讽、隐喻其他游戏厂商或对攻击其他游戏玩家等；

​​ 3.3.4 认证账号在回复评论、小组发言、或与他人私信时应做到文明用语、友好交流。

  

**处理规则：**

针对上述违规行为，平台将执行以下阶梯式处罚机制：

首次违规： 予以警告，并对该游戏圈账号实施全场景禁言及禁止发布内容3天的处理；

多次违规： 视情节严重程度，将升级处罚力度，对账号实施7天至永久的全场景禁言及禁止发布内容处理；情节极端恶劣者，将永久收回账号使用权限（封号）。
