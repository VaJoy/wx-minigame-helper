# 大盘性能监控  
  
## 概述

游戏发布上线后，对于线上用户的真实运行数据的监控和关注是非常有必要的。平台目前主要是提供了[评测标准](<../tools/perf-mesure.md>)和[数据助手](<https://developers.weixin.qq.com/minigame/analysis/assistant>)两个工具给游戏研发团队。平台通过对标准和数据的整合，面向开发者提供一个较为全面的大盘性能监控系统，目的是为了能够帮助开发者快速了解游戏整体的性能情况，系统主要有如下的几个方面的特点：

  * 掌握游戏的性能表现 —— 基于游戏线上真实用户的运行数据，依据小游戏评测标准，对关键指标数据进行收集和分析，并对指标数据结果进行评分，向开发者输出游戏的性能日报
  * 获取游戏相关的优化指引 —— 依据平台历史经验，针对关键指标提供相关的优化建议，帮助开发者对性能问题进行快速定位和解决
  * 针对异常指标进行监控 —— 对于关键指标，依据游戏自身需求，设定指标异常告警监控，及时发现游戏线上版本问题

## 使用流程

### 功能开通

对于首次进入大盘性能监控模块，开发者需要手动开通一下性能监控模块的功能，特别是通过快适配方案接入的小游戏，请遵照开通的相关流程以及游戏类型的定义，修改为与游戏本身匹配的游戏类型（快适配类型游戏默认都为**中度类型** 游戏），对于非快适配方案接入的游戏，无需进行游戏品类的修改，默认按照游戏注册时选择的品类进行归类。

### 功能使用

开发者可以切换不同的性能模块，查看启动、运行和网络性能指标、指标值及其得分，在得分的右侧，会展示当前游戏品类（类型）的评测标准，同时，对于**得分 <90分**的指标项，系统会展示相关的优化建议，开发者可遵照相关**优化建议** ，对游戏相关性能指标进行优化。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/4ef0ef40-19d2-4132-9ebc-65dbe9c7fd4c.png)

**注意：**

  1. 对于快适配类型接入的游戏，可遵照游戏本身的迭代，修改游戏当前归属的游戏类型，但修改后的游戏类型**不会改变** 历史的性能报告数据，仅影响修改后的新生成的报告数据。
  2. 平台不支持对历史性能报告数据进行重新计算。

### 评分规则

具体的性能指标与评分方法，可参照[评分规则文档](<perf-system-rating-rule.md>)进行了解。
