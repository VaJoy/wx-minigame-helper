# 技术手册

## 设备兼容篇

### 概述

随着微信小游戏底层能力的不断完善和用户设备的不断升级，玩家对于游戏品质的要求越来越高，如何在提升品质的同时，又要做到游戏能覆盖到绝大部分的游戏用户群体，是所有开发者不得不面对的问题。

《微信小游戏开发者技术手册-设备兼容篇》，通过微信小游戏数据平台，对大盘数据进行统计分析，从设备硬件、平台特性兼容、网络三个方面，为开发者提供多种维度的数据参考，旨在帮助广大游戏开发者做出更加合理的技术选型决策。
