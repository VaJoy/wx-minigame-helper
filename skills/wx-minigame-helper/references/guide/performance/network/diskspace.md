# 空间提升

为让小游戏提供更好的品质体验（美术、特效、动画等），游戏可申请将本地用户可用存储空间从200MB提升至 **1G** 。为保护用户设备的可用空间，在用户设备可用空间告警时，系统会对用户游戏缓存以游戏粒度进行清理，请开发者合理使用。

## 开通条件

  * 上传小游戏通用素材封面，可应用至搜索、游戏中心、视频号、CPS推荐组件等微信内主要场景

## 开通方式

[登录MP管理后台](<https://mp.weixin.qq.com/>) \- 功能 - 游戏能力地图 - 研发能力 - 生产提效包 - 空间提升
