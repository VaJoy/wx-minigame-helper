# 小游戏云测试

## 使用指南

小游戏云测试是微信小游戏团队为开发者提供的一套完整易用的在线测试服务，以帮助开发者更高效、更全面地进行自动化游戏性能测试、兼容性测试，驱动产品质量提升和优化，为用户带来更佳的游戏体验。 目前云测试免费为所有小游戏开放，更多使用方法更查阅[小游戏云测试使用指南](<https://developers.weixin.qq.com/minigame/dev/minigame-testtool/overview>)。

## 云测试录制回放

支持在微信开发者工具录制一段内容，然后在云测试的真机集群中回放录制过程中的所有操作，极地大提升了测试覆盖率。更多录制回放介绍可查阅[录制回放](<https://developers.weixin.qq.com/minigame/dev/minigame-testtool/record>)。

## 自定义测试框架

MiniGameTest 是一套由微信测试团队自主研发的、为微信小游戏提供的自动化测试框架，可以帮助开发者简单快捷地实现对小游戏的 UI 自动化测试。更多自定义测试框架相关内容可查阅[自动化测试框架](<https://developers.weixin.qq.com/minigame/dev/minigame-testtool/frame>)。
