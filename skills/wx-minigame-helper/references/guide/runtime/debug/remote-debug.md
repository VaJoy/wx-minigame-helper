# 真机调试

真机远程调试功能可以实现直接利用开发者工具，通过网络连接，对手机上运行的小程序进行调试，帮助开发者更好的定位和查找在手机上出现的问题。详见开发工具文档 [真机调试](<https://developers.weixin.qq.com/minigame/dev/devtools/remote-debug>)
